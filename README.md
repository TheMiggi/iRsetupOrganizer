# iRsetupOrganizer
The purpose of this tool is to organize the setup files located in the Downloads folder.

English:

- Remove all setup files (.sto) from the "Downloads" directory.
  C:\Users\%userprofile%\Downloads

- Download the P1 or VRS setups (.sto file) to your "Downloads" directory
  C:\Users\%userprofile%\Downloads

- VRS setups:
  - Start the copy_ir_setups.exe, press 1 then the return key.
  - Now enter the iracing week without leading zero then press return key.
  - The setups will automatically be moved to the destination.

- P1 setups:
  - Start the copy_ir_setups.exe, press 2 then the return key.
  - The setups will automatically be moved to the destination.
  
Problems?
- It may happen that the abbreviation for the car is not in the cars_directory_names_???.json file.
  You can add the missing abbreviation there and the script will find it.

German:

- Im "Downloads" Order alle Setup-Dateien (.sto) entfernen.
  C:\Users\%userprofile%\Downloads

- Lade die P1 oder VRS setups (.sto file) in den "Downloads" Ordner
  C:\Users\%userprofile%\Downloads

- VRS setups:
  - Starte die copy_ir_setups.exe, drücke 1 und dann "Enter".
  - Nun fragt das Skript nach der Woche für die Setups. Eingabe ohne führende null und "Enter" drücken.
  - Setups werden nun automatisch verschoben.

- P1 setups:
  - Starte die copy_ir_setups.exe, drücke 2 und dann "Enter".
  - Setups werden nun automatisch verschoben.
  
  
Probleme?
- Es kann sein, dass die Abkürzung für ein Auto in der Datei cars_directory_names_???.json fehlt.
  Man kann die fehlende Abkürzung in die Datei hinzufügen und das Skript findet es dann beim nächsten Versuch.
